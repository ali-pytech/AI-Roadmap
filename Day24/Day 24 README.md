# Day 24 — Mini OOP Project: Smart Service Portal

Today I combined **all four OOP pillars** into one professional system:  
- **Encapsulation** → secure attributes with getters/setters.  
- **Inheritance** → child classes reuse parent functionality.  
- **Polymorphism** → same method behaves differently across classes.  
- **Abstraction** → enforce structure with abstract base classes.  


## Project: Smart Service Portal

### Features
- **Iqama Renewal** → encapsulated fee with validation.  
- **VAT Invoice** → calculates totals with VAT.  
- **Housing Records** → encapsulated rent with validation.  
- **Unified Service Portal** → abstract base class ensures all services implement `process()`.



##  Reflections
- This project shows **layered mastery**: multiple OOP pillars working together.  
- The Smart Service Portal is a **Saudi-context project** demonstrating practical relevance.
